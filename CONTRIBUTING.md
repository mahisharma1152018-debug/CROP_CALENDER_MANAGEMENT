# Contributing

Thanks for contributing to Crop Calendar!

## Workflow
1. Fork the repository.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Run both client and server locally.
4. Keep changes focused and beginner-readable.
5. Test the affected API/UI flow.
6. Commit with a clear message.
7. Open a pull request describing the problem and solution.

## Good first contributions
- Improve empty/loading states
- Add a crop-template activity
- Improve mobile styling
- Add validation messages

## Medium contribution tracks
- Weather-aware reminders
- Optional email reminders
- Advanced statistics charts
- Multilingual interface

Avoid committing `.env`, credentials, build output or unrelated formatting changes.
